## 📖 Overview

**Chaitanya** is a comprehensive, full-stack digital mental wellness platform initially developed for the Smart India Hackathon (SIH). It serves as a judgment-free, confidential space for students to seek psychological support, featuring a unique **Neobrutalism UI/UX** that makes the experience engaging and bold.

The platform bridges the gap between students seeking help and professional counselors by offering AI-driven interventions, gamified stress-relief workflows, and detailed mood analytics.

---

## ✨ Key Features

### 🤖 Contextual AI Support Coach
Talk it through with our empathetic AI coach trained in psychological first aid techniques. The AI listens to your concerns and recommends evidence-based activities instantly.

### 🎭 Role-Based Access Control (RBAC)
Chaitanya provides tailored portals for 5 distinct roles:
- **Student Portal:** Access to self-help tools, mood tracking, and AI chat.
- **Parent/Guardian Portal:** Monitor progress and receive wellness updates.
- **Counselor Portal:** Manage appointments, view student assessments, and provide direct chat support.
- **Institution Admin:** View aggregated campus-wide mental wellness trends via data-driven dashboards.
- **Super Admin:** Manage institutional licenses, roles, and global system health.

### 📊 Dynamic Mental Health Assessments
Evidence-based psychological assessments (inspired by PHQ-9 and GAD-7) to help students track their mental state over time with visual analytics.

### 🎮 Gamified Wellness Arcade & Mood Tracker
Keep engagement high with daily check-ins, a gratitude journal, and an interactive arcade of relaxation exercises.

### 🤝 Anonymous Peer Forum
A safe, moderated space for students to connect anonymously with peers and trained volunteers.

## 🎨 Design System

Chaitanya features a custom-built **Neobrutalism** design system. Moving away from typical corporate aesthetics, it uses:
- Hard, solid black drop shadows.
- Thick, stark borders.
- Vibrant, unapologetic high-contrast colors.
- Bold typography.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/DeepakSinghhh/amigo.git
   cd chaitanya
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173` to view the application.
